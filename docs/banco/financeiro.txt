FINANCEIRO DOS INGRESSOS — 09/11/2026

Fontes: schema Prisma e migrations versionadas. Migrations aplicadas ao PostgreSQL local nesta revisao.
Nenhum comprovante, CPF, senha, chave Pix real ou registro de cliente foi exportado neste documento.

NOVOS RELACIONAMENTOS
Ticket.financialPolicy: JSONB opcional com regra capturada ao reservar; nao e exposto ao torcedor.
TicketPayment 0..1 TicketFinancial, por paymentId UNIQUE.
TicketFinancial 1:N TicketFinancialEntry; revisao unica por apuracao, com deltas preservados.
User 1:N ClubPayout; ator registra repasse manual, sem transferencia bancaria pela API.
GatewayIntent 0..1 TicketRefundCost: tarifa retida de cobranca devolvida sem emissao.

CONVENCOES
Valores em centavos inteiros. Percentuais em pontos-base: 1000 = 10%.
companyCents e a comissao acumulada, clubCents pode ficar negativo apos estornos/tarifas.
companyBps inicial 1000; commissionBase inicial NET; payoutWeekday 5 = sexta-feira.
ClubPayout.balanceBeforeCents e BIGINT; a API converte para Number no JSON e limita valores seguros.
Anular repasse preserva referencia e valores, preenche voidedAt/voidReason e gera auditoria.
Nada apaga vendas ou faz uma transferencia real ao registrar um repasse.

model TicketFinancial {
  id String @id @default(uuid()) @db.Uuid
  paymentId String @unique @db.Uuid
  policy Json
  grossCents Int
  refundedCents Int @default(0)
  gatewayFeeCents Int
  feeSource String @db.VarChar(20)
  companyCents Int
  clubCents Int
  blocked Boolean @default(false)
  version Int @default(0)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  payment TicketPayment @relation(fields: [paymentId], references: [id], onDelete: Restrict)
  entries TicketFinancialEntry[]
  @@index([blocked, feeSource])
}

model TicketFinancialEntry {
  id String @id @default(uuid()) @db.Uuid
  financialId String @db.Uuid
  revision Int
  grossDeltaCents Int
  refundedDeltaCents Int
  gatewayDeltaCents Int
  companyDeltaCents Int
  clubDeltaCents Int
  reason String @db.VarChar(200)
  createdAt DateTime @default(now())
  financial TicketFinancial @relation(fields: [financialId], references: [id], onDelete: Restrict)
  @@unique([financialId, revision])
  @@index([createdAt])
}

model ClubPayout {
  id String @id @default(uuid()) @db.Uuid
  actorId String @db.Uuid
  requestKey String @unique @db.VarChar(80)
  requestHash String @db.VarChar(64)

  reference String @unique @db.VarChar(100)
  recipient String @db.VarChar(200)
  transferredAt DateTime
  notes String @default("") @db.VarChar(1000)
  voidedAt DateTime?
  voidReason String? @db.VarChar(500)
  createdAt DateTime @default(now())
  actor User @relation(fields: [actorId], references: [id], onDelete: Restrict)
  @@index([createdAt])
}

model TicketRefundCost {
  id String @id @default(uuid()) @db.Uuid
  intentId String @unique @db.Uuid
  grossCents Int
  refundedCents Int
  gatewayFeeCents Int
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  intent GatewayIntent @relation(fields: [intentId], references: [id], onDelete: Restrict)
}

REGRA DE CONFERENCIA
bruto - devolucoes = gateway + empresa + time.
Saldo pendente do time = parte apurada do time - repasses nao anulados.
Tarifa estimada ou recebimento bloqueado nao libera novo repasse.
A tarifa de um pagamento devolvido sem emissao e incluída uma vez por GatewayIntent.
Guia funcional e limites: docs/financeiro-ingressos.md.
